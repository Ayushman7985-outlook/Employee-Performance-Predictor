# 📊 Employee Performance Predictor using Data Analytics

A beginner-friendly, industry-oriented **data analytics and machine learning portfolio project** using a reproducible synthetic HR dataset. It includes data generation, validation, exploratory analysis, two classification baselines, held-out evaluation, automated tests, and an interactive Streamlit dashboard.

> **Responsible-use note:** All records and outcomes are synthetic. Model metrics demonstrate a software workflow only; they do not establish real-world validity. Do not use this demo to make employment, promotion, compensation, termination, or other consequential decisions about real people.

## Project objectives

- Generate reproducible fictional employee records without confidential HR data.
- Validate data and summarize the dataset.
- Explore score distributions and aggregate department patterns.
- Train Logistic Regression and Random Forest classifiers.
- Compare accuracy, weighted precision, weighted recall, weighted F1, and confusion matrices.
- Predict a synthetic performance category for a hypothetical profile.
- Present the results in an interactive Streamlit application.
- Test core functionality with Pytest.

## Dataset

The generator creates 500 fictional records by default with:

- Department and job role
- Years of experience
- Training hours
- Attendance percentage
- Job satisfaction rating
- Previous performance score
- Synthetic performance score and derived category

The generator uses a fixed random seed so results are reproducible. The outcome is generated by a formula plus random noise. Therefore, model performance mostly reflects patterns embedded in the simulation and must not be interpreted as evidence about actual workplaces.

## Installation

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If script activation is blocked, run the environment interpreter directly:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

After creating the project folders, save the source files shown in the repository structure above.

## Run the pipeline

```bash
python main.py
```

The command generates `data/employees.csv`, validates the dataset, writes exploratory charts into `outputs/`, trains and evaluates both classifiers, saves the selected model to `models/performance_model.joblib`, and prints an example prediction.

## Launch the dashboard

```bash
streamlit run app.py
```

Open the local URL printed by Streamlit in your browser. Use the sidebar to explore the overview, data analysis, model evaluation, and hypothetical prediction pages.

## Run tests

```bash
python -m pytest -q
```

A successful run should show all tests passing. Test results can vary if you change the generator, model, or dependencies.

## Evaluation

The training pipeline reports:

- Accuracy
- Weighted precision
- Weighted recall
- Weighted F1
- Classification report
- Confusion matrix

The best baseline is selected by weighted F1 on a held-out test split. The test set is used for final evaluation, not for fitting preprocessing transformations. For a stronger study, add cross-validation and test on independently sourced, ethically approved data.

## Limitations and responsible use

- Data is synthetic and does not represent a real employer or workforce.
- Synthetic labels are generated from an artificial formula, so high test metrics may be expected and are not evidence of workplace validity.
- Attendance, satisfaction, training, and historical scores may reflect structural or contextual differences. They should not be treated as objective measures of employee worth.
- Predictions should not be used for high-impact employment decisions.
- Any future real-world study would need appropriate data permissions, privacy protections, validation, domain review, and rigorous fairness and impact assessments.
